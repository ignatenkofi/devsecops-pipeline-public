# devsecops-pipeline-public

Публичный компаньон [devsecops-pipeline](https://github.com/ignatenkofi/devsecops-pipeline):
лёгкие security-стадии как переиспользуемый GitHub Actions workflow для
**публичных** репозиториев (public→public), плюс учебный слой — конвейер
показывается как живой пример «shift-left security» на занятиях.

Полное README и реализация — в первом PR.
